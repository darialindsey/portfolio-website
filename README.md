# Daria's Portfolio 
A two-page personal portfolio website built with HTML, CSS, JavaScript. I am a career changer learning PERN fulls-tack development and I built this site to show what I can do. 
## Features
- Terminal-style hero with typing animation and blinking cursor
- Day / Night / Auto theme toggle that remembers preference
- Two pages linked by shared navigation bar
- Contact form with required name + email fields
- Responsove layout for phone, tablet, desktop screens

## What I learned: 
- Debugging after breaking day/night/auto theme (punctuation, missing brackets misnamed variables)
- Making a site more accessible and easier to navigate with a screen reader
